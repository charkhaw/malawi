# 3. Governance

## 3.1 Roles, decisions and reporting

The plan uses the project bodies that already exist, and adds only a change board for technical
change.

| Role or body | Responsibility |
|---|---|
| Project Steering Committee | Receives the change and readiness status monthly; decides any readiness gate referred to it |
| Purchaser's Project Manager | Approves the processes, procedures and readiness at each gate |
| Supplier's Representative | Coordinates the Supplier's work and reports monthly |
| Training and Change Management Specialist | Owns this plan: impact on each group, support to NRB's engagement, procedure adoption, and the readiness evidence for each gate |
| Change board | Solution Architect as Supplier technical lead, NRB ICT manager, NRB operations manager, and the NRB security officer for security-relevant changes. Approves technical changes under Section 5. Meets weekly from the start of installation in week 15, and monthly or on demand in operation. Chaired by NRB from handover |
| NRB process owners | Own each process and its procedures from handover |

| Decision | Decided by |
|---|---|
| Approval of processes, roles and procedures | Purchaser's Project Manager |
| Timing of cutover, for each request type | NRB |
| Readiness at each gate | Purchaser's Project Manager, on the Steering Committee's recommendation |
| Normal technical change | Change board |
| Emergency technical change | Incident manager or NRB ICT manager, and reviewed at the next change board |
| Change to scope, price or time | The Purchaser, by Change Order under GCC 39 |
| Withdrawal of the existing card printers | NRB, after operational acceptance test 2 |

**Separation of duties.** No one approves a change they requested or implement, developers do not
deploy to production, and the operator who runs a job is not the supervisor who releases it.

**Reporting.** Change and readiness status is part of the Monthly Progress Report under GCC 19.5,
including the actions expected from NRB in the next period. Training reports are issued under SCC
19.6(b), and the Change Order Log is kept with the progress reports. From handover, adoption issues and
changes made in the period are reported in the monthly service report of Preliminary Project Plan
Section 5.6. No other report is added.
